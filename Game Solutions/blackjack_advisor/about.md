# 🃏 [Blackjack Strategy Advisor](/Game%20Solutions/blackjack_advisor/blackjack_strategy_advisor.py)
I always wanted to know the mathematically optimal move in Blackjack based on probabilities rather than pure luck. To solve this, I built a script that replicates the game's core matrix rules. This tool calculates whether to hit, stand, or double down, helping players significantly reduce the house edge.

## 💻 Code and Logic
The code is made of basic concepts in Python, meaning anyone can understand it with a quick glance.

*What it does:* It asks for the player's initial card values and the dealer's visible face-up card. Using this data, the program evaluates the player's hand total against established mathematical thresholds to instantly provide the best strategic action (Hit, Stand, or Double).
