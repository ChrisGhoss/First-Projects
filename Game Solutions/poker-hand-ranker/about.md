# 🃏 [Poker Hand Evaluator](/Game%20Solutions/poker-hand-ranker/hand_ranker.py)
I always wanted to automatically determine the strength of a 5-card poker hand without manually checking the combinations, this way there are no errors. I built a script that analyzes standard card ranks and suits. This tool calculates the exact poker hand ranking, helping players quickly identify their hand strength.

## 💻 Code and Logic
The code is made of basic concepts in Python, meaning anyone can understand it with a quick glance.

*What it does:* It asks for five inputs representing a player's card hand using a standardized text format. Using this data, the program checks for matching ranks, consecutive sequences, and matching suits to instantly classify the hand from a simple Pair all the way up to a Royal Flush.
