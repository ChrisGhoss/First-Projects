# 🪑 [Table Capacity](/House%20Solutions/table-capacity/table_amount_solver.py)
Counting guests to estimate how long a table should be has always been a challenge, especially when the number of guests is uncertain and only confirmed at the last second. This program solves just that, with great accuracy too! I was inspired by the constant struggle of not having enough tables for every guest, but by using this program everyone can sit comfortably without feeling too crowded.

## 💻 Code and Logic
The code is made of basic concepts in Python, meaning anyone can understand it with a quick glance.

*What it does:* It asks for two simple inputs: The number of guests and whether some will sit on the ends of the table. It then uses this information to calculate the total length of the desired table that fits every guest.
