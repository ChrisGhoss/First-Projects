# 🖼️ [Frame Space Estimator](/House%20Solutions/frame-spacing/frame_spacing_calculator.py)
Like my most of my projects, I was inspired by looking around my room when I saw some paintings lined up in a single row and noticed that the spacing between them was the same. This gave me the idea to make a program that lets you find the measurement of that gap, depending on the number of frames and the width of the wall.

## 💻 Code and Logic
The code is made of basic concepts in Python, meaning anyone can understand it with a quick glance.

*What it does:* It asks for multiple inputs: the width of your wall, the number of frames, and whether they are all the same size (entering the width of one frame once, or entering each individually). It then calculates the exact measurement of each gap in centimeters.
